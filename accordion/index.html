아코디언 V6

섹션을 채우면 오른쪽에 아임웹 화면처럼 보여줍니다

제품

제품 표기는 코드 맨 위 주석에 들어갑니다. 브랜드를 적으면 그 브랜드로 저장해 둔 '브랜드 이야기'를 자동으로 채웁니다.

섹션 구성 제품 종류에 맞춰 3번 섹션을 바꿉니다

섹션

    내용 쓰는 법
    • 빈 줄로 문단을 나눕니다. 줄만 바꾸면 같은 문단 안에서 줄이 바뀝니다.
    • 항목 | 내용 으로 쓴 줄이 이어지면 스펙 표가 됩니다 (왼쪽 칸 회색 바탕, 위쪽 2px 검은 선).
    • ## Rotary Ring | 로터리 방식 은 영문 소제목 + 회색 한글 부제가 됩니다.
    • **배송** 평일 오후 3시… 처럼 별표 두 개로 감싼 글자는 굵은 라벨이 됩니다.
    • ※ 로 시작하는 줄은 12px 회색 주석이 됩니다.
    • - 로 시작하는 줄은 목록이 됩니다.
    • [보이는 글자](https://주소) 로 링크를 겁니다. 맨 주소도 자동으로 링크가 되고, 새 창으로 열립니다.

    초안 이 브라우저에만 저장됩니다

    미리보기 서체는 에스코어 드림입니다. 아임웹 헤더 코드에 S-CoreDream @font-face가 있어야 실제 화면에도 같은 서체가 나옵니다.

    기존 코드 불러오기

    아임웹 상품 상세에 들어 있는 v5 또는 v6 아코디언 코드를 통째로 붙여 넣으면 섹션과 내용을 읽어 옵니다. v5 코드면 공통 섹션(배송 · 교환/반품 · A/S)을 v6 문구로 바꿉니다. 지금 편집 중인 내용은 바뀝니다.
